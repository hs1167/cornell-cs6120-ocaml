# 3 · Local Analysis & Optimization

- Implémenter la *trivial dead code elimination* (TDCE) et le *local value numbering* (LVN).
- Évaluer la correction et les gains sur des programmes Bril, y compris lorsque les deux optimisations sont combinées.
- Bonus Cornell · étendre le LVN aux cas plus difficiles de la leçon.

La configuration Brench à la racine permet de mesurer le nombre dynamique d’instructions.
